Labelled text input with uppercase micro-label and blue focus ring.

```jsx
<Input label="Họ và tên" required placeholder="Nguyễn Văn A" />
<Input label="Email" required type="email" placeholder="email@example.com" />
```

Pair with `Select` and `Textarea` (same field styling). Use `required` to append " *". Lay fields out in a `display:grid; gap:10px` two-column row for compact forms.
