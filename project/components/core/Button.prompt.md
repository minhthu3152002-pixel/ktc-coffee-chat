Primary action button — use for CTAs like "Đăng ký ngay" and form submits.

```jsx
<Button variant="primary" arrow>Đăng ký giữ slot</Button>
<Button variant="outline" size="sm">Xem chi tiết</Button>
<Button variant="navy" full>Gửi đăng ký</Button>
```

Variants: `primary` (royal blue, default) · `navy` (deep brand) · `accent` (KTC pink) · `outline` · `ghost`.
Sizes: `sm` · `md` · `lg`. Props: `href` (renders <a>), `arrow`, `full`, `disabled`.
